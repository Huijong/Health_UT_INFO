1단계: 테스터 프로필 입력 화면 (Page 1)
[Premium Design - Page 1: Tester Profile]
테스터의 기본 정보(이름, 키, 몸무게, 워치 종류)를 입력받는 첫 번째 화면을 디자인해줘.

- 비주얼 가이드: 배경은 부드러운 그라데이션이 들어간 Deep Indigo와 화이트 톤의 깔끔한 글래스모피즘 카드를 얹어줘.
- 구성 요소:
  1. 상단의 직관적인 단계별 진행 상황을 나타내는 가로형 스태퍼(Stepper) 바 (1/5 완료 상태)
  2. 둥근 모서리와 은은한 그림자가 들어간 입력용 카드 섹션
  3. "테스터 이름", "키 (cm)", "몸무게 (kg)"를 입력하는 라운드 테두리의 프리미엄 텍스트 필드 (세련된 좌측 아이콘 포함)  
  4. 하단의 "다음 단계로 (Next)" 버튼 - 브랜드 메인 컬러와 탭 시의 호버링 피드백이 적용된 플로팅 스타일로 구성해줘.

5단계: 검증 대상 파일 첨부 화면 (Page 5)
[Premium Design - Page 2: File Attachment]
4단계에서 각각의 운동의 제출 버튼을 누르면 진입하는 검증에 필요한 로우 데이터 파일(FIT, Cola.zip, 로그 파일, 화면 캡처)을 첨부하는 화면을 디자인해줘.

- 비주얼 가이드: 어둡지 않은 세련된 모던 라이트 테마에 네온 민트(Neon Mint) 포인트를 줘서 건강하고 정밀한 느낌을 표현해줘.
- 구성 요소:
  1. 상단의 진행 상황 스태퍼 바 (5/5 완료 상태)
  2. 각 파일 종류별로 별도의 전용 카드 섹션을 시각화:
     - **FIT 파일 추가**: 스포티한 덤벨 아이콘, 파일 첨부 시 리스트에 둥근 칩(Chip) 형태로 파일명과 용량이 추가되는 모습
     - **Cola.zip 추가**: 세련된 ZIP 아이콘, Documents/COLA_FILE 경로 힌트가 우측에 연하게 배치됨
     - **로그 파일 추가**: 짙은 그레이 아이콘, log_*.zip 파일 첨부 힌트가 들어감
	 - **운동 캡처 선택 (다중)**: 갤러리 접근 버튼을 누르면 밑에 첨부된 이미지들이 둥근 모서리의 그리드 썸네일(Grid Thumbnail)로 배치되고, 썸네일 우측 상단에 이미지 삭제를 위한 미니 'X' 배지가 예쁘게 들어간 UI
  3. 파일이 비어 있을 때 보여지는 부드러운 점선 테두리(Dotted Border)의 "파일을 선택해 주세요" 빈 상태(Empty State) 일러스트/아이콘 UI
  4. 착용 위치를 스위치 UI로 선택할 수 있게 구현 ( 왼쪽, 오른쪽 )
  5. 착용 정도를 스위치 UI로 선택할 수 있게 구현 ( 충분히, 정닥히, 느슨하게)
  6. 동시에 착용한 타사 모델  선택할 수 있게 후현 ( 가민, 애플, 크로스) 및 직접입력 시 나타나는 서브 텍스트 필드    
  7. 훈련 종류를 선택하는 둥근 드롭다운 메뉴 (조깅, 인터벌, LSD, 변속주, 지속주) 및 직접입력 시 나타나는 서브 텍스트 필드
  8. 장소를 직접입력 할수 있는 텍스트 필드
  9. **특이 사항**: 높이가 확보된 부드러운 라운드 텍스트 영역(TextArea)으로, "특이 사항이 있다면 적어주세요"라는 힌트 제공
  10. 보내기 버튼

6단계: 패키징 및 전송 완료 화면 (Page 6)
[Premium Design - Page 4: Packaging & Transmission]
데이터를 압축하고 Quick Share 링크를 확인하여 이메일로 전송하는 최종 화면을 디자인해줘.

- 비주얼 가이드: 완료 상태의 신뢰감을 줄 수 있도록 성공(Success)을 뜻하는 에메랄드 그린과 딥 블루가 어우러진 대시보드형 완료 카드 디자인.
- 구성 요소:
  1. 상단의 진행 상황 스태퍼 바 (5/5 완료 상태 - 빛나는 체크 표시 적용)
  2. 중앙에 회전하는 네온 프로그레스 서클(Progress Circle) 또는 세련된 패키징 완료 애니메이션 그래픽 배치
  3. **압축 완료 정보 카드**: 생성된 zip 파일명, 파일 전체 크기, 압축된 파일 개수가 디테일하게 나열된 인포 카드
  4. **전송 상태 패널**:
     - "Quick Share 링크 복사 대기 중..." ➡️ 클립보드 감지 시 "링크 획득 성공 (도메인 주소 표시)" ➡️ "이메일 발송 완료" 단계로 이어지는 미려한 타임라인(Timeline) 형태의 상태 가이드 UI
     - 수동으로 메일을 보낼 수 있는 "메일 다시 보내기" 보조 버튼
  5. 메인 하단 버튼: "새로운 검증 시작하기" (데이터 초기화 및 1단계로 이동)
