자동 동기화 방법

모바일 핫스팟을 이용해 워치의 COLA / Log 파일을
Healport 앱으로 손쉽게 전송하는 방법을 안내합니다.

1
"2. 워치 COLA / Log 파일 동기화" 선택
Healport 앱 메인 화면에서 두 번째 항목을 탭합니다.
2
"설정 열기" 선택
핫스팟 설정 상태 영역에 표시된 설정 열기 버튼을 탭합니다.
3
"모바일 핫스팟 켜기" 켜기
스위치를 켜서 모바일 핫스팟을 활성화합니다.
4
"워치와 연결 시작" 선택
Healport 앱으로 돌아와 워치와 연결 시작 버튼을 탭하면 자동으로 동기화가 진행됩니다!
1
"2. 워치 COLA / Log 파일 동기화" 선택
Healport 앱 메인 화면에서 두 번째 항목을 탭합니다.
2
"설정 열기" 버튼 선택
핫스팟 설정 상태 영역에 표시된 설정 열기 버튼을 탭합니다.
3
"설정 열기" — 핫스팟 정보 확인 후 선택
안내에 따라 본인 상황에 맞게 1번 또는 2번을 선택합니다.
아래 참고 안내를 읽고 선택하세요
💡
Step 3 참고: 핫스팟 이름이 healthport, 비밀번호가 00000000이라면 1번을 선택하세요. 이름/비밀번호가 다르다면 2번 선택 후 Step 5에서 직접 설정해 주세요.
4
"모바일 핫스팟" 설정 페이지 진입
안드로이드 시스템의 모바일 핫스팟 설정 화면이 열립니다.
5
네트워크 이름 / 비밀번호 / 밴드 변경
Step 3에서 2번을 선택한 경우, 핫스팟 이름을 healthport, 비밀번호를 00000000으로 설정하거나 원하는 값으로 변경합니다.
6
"모바일 핫스팟" 켜기
스위치를 켜서 모바일 핫스팟을 활성화합니다. 워치가 이 핫스팟에 자동 연결됩니다.
스위치를 ON으로 전환하세요
7
"워치와 연결 시작" 선택
Healport 앱으로 돌아와 워치와 연결 시작 버튼을 탭합니다.
8
"앱 사용 중에만 허용" 선택
위치 권한 요청 팝업이 나타나면 앱 사용 중에만 허용을 선택합니다.
9
"허용" 선택
추가 권한 요청 팝업에서 허용을 탭합니다.
10
"연결 시작" — 워치와 연동 시작
워치와의 Wi-Fi 연결이 시작됩니다. 워치 앱에서도 연동이 진행됩니다.
11
"앱을 사용 중일 때" 선택
워치 앱에서 위치 권한을 요청합니다. 앱을 사용 중일 때를 선택하세요.
12
"허용" 선택
워치 앱 권한 팝업에서 허용을 탭합니다.
13
"허용" 선택
추가 권한 요청 팝업에서 다시 허용을 탭합니다.
14
워치와 연결됨 확인
워치와 핫스팟을 통한 Wi-Fi 연결이 완료되었습니다.
15
"확인" 선택 — 폰과 연동 허락
워치 화면에서 폰과의 연동을 허락하는 확인 버튼을 탭합니다.
16
워치 앱 — 연동 시작
워치 앱에서 자동으로 데이터 전송이 시작됩니다. 잠시 기다려 주세요.
17
자동 다운로드 시작
Healport 앱에서 워치의 COLA 및 Log 파일 다운로드가 자동으로 진행됩니다.
✓
자동으로 파일 첨부 완료!
다운로드받은 COLA / Log 파일이 Healport 앱에 자동으로 첨부됩니다. 이제 건강 검사를 진행하세요!
