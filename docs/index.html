Galaxy Watch 데이터
자동 동기화 방법

1
"2. 워치 COLA / Log 파일 동기화" 선택
HealthPort 앱 메인 화면에서 두 번째 항목을 탭합니다.
✓
"워치와 연결 시작" 선택
워치와 연결 시작 버튼을 탭합니다.
💡
참고: 만약에 "워치와 연결 시작"이 비활성화 되어 있으면 핫스팟을 켜주세요.
1
"2. 워치 COLA / Log 파일 동기화" 선택
HealthPort 앱 메인 화면에서 두 번째 항목을 탭합니다.
2
"핫스팟 설정 열기" 버튼 선택
핫스팟 설정 상태 영역에 표시된 설정 열기 버튼을 탭합니다.
3
"모바일 핫스팟" 켜기
안드로이드 시스템의 모바일 핫스팟 설정 화면이 열립니다.
4
"확인" 버튼 선택
확인 버튼을 탭합니다.
5
네트워크 이름 복사 / 비밀번호 복사 / 밴드 변경
네트워크 아이디와 비밀번호를 복사해오고 밴드는 5GHz로 변경합니다.
6
네트워크 이름 / 비밀번호 넣기
네트워크 이름과 비밀번호를 입력합니다.
7
"워치와 연결 시작" 선택
워치와 연결 시작 버튼을 탭합니다.
8
"앱 사용 중에만 허용" 선택
위치 권한 요청 팝업이 나타나면 앱 사용 중에만 허용을 선택합니다.
9
"허용" 선택
추가 권한 요청 팝업에서 허용을 탭합니다.
10
"연결 시작" — 워치와 연동 시작
워치와의 Wi-Fi 연결이 시작됩니다. 워치 앱에서도 연동이 진행됩니다.
11
"앱을 사용 중일 때" 선택
워치 앱에서 위치 권한을 요청합니다. 앱을 사용 중일 때를 선택하세요.
12
"허용" 선택
워치 앱 권한 팝업에서 허용을 탭합니다.
13
"허용" 선택
추가 권한 요청 팝업에서 다시 허용을 탭합니다.
14
워치와 연결됨 확인
워치와 핫스팟을 통한 Wi-Fi 연결이 완료되었습니다.
15
"확인" 선택 — 폰과 연동 허락
워치 화면에서 폰과의 연동을 허락하는 확인 버튼을 탭합니다.
16
워치 앱 — 연동 시작
워치 앱에서 자동으로 데이터 전송이 시작됩니다. 잠시 기다려 주세요.
17
자동 다운로드 시작
HealthPort 앱에서 워치의 COLA 및 Log 파일 다운로드가 자동으로 진행됩니다.
✓
자동으로 파일 첨부 완료!
다운로드받은 COLA / Log 파일이 HealthPort 앱에 자동으로 첨부됩니다.
