[목표] 현재 앱의 "검증 파일 및 디테일 등록" 화면을 테스터 친화적(자동화 중심) UX/UI로 전면 개편해 줘. 사용자가 직접 첨부하는 수고를 최소화하고, 예외 상황에는 수동으로 대처할 수 있도록 아래 3개의 섹션으로 나누어 구현할 것.

[섹션 1: 기본 운동 데이터 (수동)]

UI 구성: "1. 기준 FIT 파일 첨부", "2. 운동 결과 캡처 이미지 첨부"
기능: 기존과 동일하게 유저가 버튼을 눌러 파일 탐색기나 갤러리에서 직접 파일을 선택하도록 구현.
[섹션 2: 비교 데이터 (자동화)]

UI 구성: "3. Garmin Fit 파일 첨부"
자동화 로직:
화면 진입 시 /sdcard/Download/ 폴더를 자동으로 스캔하여 Garmin 관련 압축파일(.zip 또는 .fit)이 있으면 자동으로 첨부하고 체크(✅) 표시할 것.
사용자가 파일을 다운받기 위해 앱을 나갔다가(Background) 다시 돌아왔을 때(Foreground / didPopNext 등 화면 복귀 시) 폴더를 재탐색하여 새로운 파일이 생겼다면 자동으로 낚아채서 첨부할 것.
[섹션 3: 분석용 시스템 로그 (스마트 동기화 + 수동 폴백)]

UI 구성:
상단: 눈에 띄는 큰 버튼 🚀 워치에서 자동으로 가져오기
하단: 📁 COLA 파일 (터치하여 수동 선택), 📁 Log 파일 (터치하여 수동 선택) 빈칸 슬롯 제공.
자동화 시나리오 (🚀 버튼 클릭 시):
*#9900# 단말 로그 덤프 유도 팝업 노출 ("덤프를 수행하셨나요? [네] / [가이드 보기]").
[네] 클릭 시, "실험실 - 워치 동기화" 모바일 핫스팟 화면으로 자동 이동 및 "탐색 시작" 버튼 로직이 자동 실행되도록 연동.
동기화가 성공적으로 끝나고 다시 이 화면으로 돌아오면, /sdcard/Documents/COLA_FILE/ 경로의 COLA_*.zip과 log_*.zip 파일을 찾아 하단의 빈칸 슬롯에 자동 첨부(✅) 할 것.
수동(Fallback) 시나리오:
유저가 🚀 버튼을 누르지 않고 하단의 📁 COLA 파일이나 📁 Log 파일 빈칸을 직접 터치하면 일반 파일 탐색기가 열리도록 구현.
이미 파일이 채워진 상태라도 ❌ 버튼을 눌러 비운 뒤 다시 수동 첨부할 수 있도록 할 것.

디자인은 기존 앱의 다크 테마(Color(0xFF1A2035) 등)와 어울리도록 세련되고 직관적인 카드형 UI로 구성해 줘.
코드를 작성하기 전에 현재 내 파일(lab_..._screen.dart 등)의 구조를 분석하고, 변경될 내용을 먼저 브리핑해 줘

둥둥 떠다니는 효과 (Bobbing): 말풍선이 위아래로 아주 살짝(2~3픽셀 정도) 천천히 둥둥 떠다니는 루프 애니메이션(SlideTransition 또는 TweenAnimationBuilder 활용)을 넣으면 굉장히 귀엽고 시선을 끕니다.
팝업 효과 (Pop-in): 화면에 진입하고 0.5초 정도 뒤에 말풍선이 작았다가 '띠용~' 하고 커지면서 나타나게(ScaleTransition) 만들 수도 있습니다.
